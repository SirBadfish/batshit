Batshit Geist font files
========================

Source: `geist@1.7.1` from npm, published by Vercel.

Geist Sans and Geist Mono are the fallbacks behind Nunito Sans and Google Sans Code, and still the fonts Artifacts generate with (served to artifacts by `/artifact-assets/fonts/geist/`).

Included files:
- `Geist-Variable.woff2`
- `GeistMono-Variable.woff2`
- `LICENSE.txt`

Only the Sans and Mono variable WOFF2 files are bundled. Geist Pixel is intentionally excluded from Batshit. App typography uses 300 as the normal reading weight, 500 as the standard emphasis weight, and 15px (`0.9375rem`) for compact chat markdown.
