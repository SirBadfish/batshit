# Support

Batshit is alpha self-hosted software. Expect active iteration and some rough edges.

## Start here

- Docs: [docs.batshit.ai](https://docs.batshit.ai/)
- Intro playlist: [Informal Alpha Release: Introduction to Batshit](https://www.youtube.com/watch?v=hS3NfNPgW70&list=PLeodpgBXojRy4Ssreao79TIX7PylhiI1D)
- Community: [Batshit Discord](https://discord.gg/3saVHX5xn)

## GitHub issues

Use GitHub Issues for reproducible bugs, focused documentation problems, and concrete feature requests.

Please include:

- setup path: Mac app, Docker, or source checkout
- what you expected
- what happened
- steps to reproduce
- screenshots for visual bugs
- the diagnostics zip from Settings -> Admin -> Diagnostics, if Batshit opens far enough to export one

Review the diagnostics preview before sharing the zip publicly. Do not include API keys, tokens, raw private logs, private files, or sensitive local paths.

## Security

Do not open a public issue for suspected vulnerabilities, auth bypasses, sandbox escapes, token exposure, or other security problems. Use the private reporting path in [SECURITY.md](SECURITY.md).
