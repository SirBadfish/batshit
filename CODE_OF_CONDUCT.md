# Code of Conduct

Batshit is an alpha open-source project for AI builders, n8n users, local-runtime tinkerers, and people trying weird ambitious workflows. Keep the project space useful, direct, and respectful.

## Expected behavior

- Be kind and constructive.
- Assume people may be new to GitHub, self-hosting, AI tooling, n8n, Docker, or Mac app setup.
- Keep bug reports and feedback focused on the behavior, not the person.
- Respect privacy. Do not post API keys, tokens, private logs, screenshots with secrets, or someone else's personal information.
- Use the security reporting path in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

## Unacceptable behavior

- Harassment, threats, slurs, or targeted personal attacks.
- Sexualized or violent harassment.
- Publishing private information without permission.
- Repeated bad-faith arguing, spam, or derailing issue/PR threads.
- Encouraging unsafe disclosure of secrets, credentials, or private user data.

## Enforcement

Maintainers may edit, hide, lock, or delete comments; close issues or pull requests; block users; or report abuse to GitHub when needed.

This project is maintainer-led. Participation is welcome, but access to the issue tracker, pull requests, discussions, or community spaces can be limited to keep Batshit safe and useful.
