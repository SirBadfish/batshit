# Batshit Anime Hair Studio Template

`Batshit-Base-Female-Hair-Template-v1.ahs` is the official calibration template for authoring polygon Hair for Batshit's first-party Base Female Goon in [Anime Hair Studio](https://github.com/Ludetools/Animehairstudio).

1. Download and duplicate the template before editing it.
2. Create the hairstyle in Anime Hair Studio without replacing or reshaping the embedded Batshit head/scalp calibration.
3. Export the finished Hair as OBJ.
4. In Batshit, choose **Import Hair** and select the exported OBJ plus the saved `.ahs` project together.
5. Inspect the objects, fit, motion map, and final preview before saving the local Hair Asset.

The OBJ is always the Hair geometry. The `.ahs` file supplies calibration only and cannot be imported by itself. Ordinary Hair edits, visibility changes, guide edits, reference images, and project resaves do not change template recognition; changing the embedded head or scalp calibration sends the project through Batshit's visible general-fit path.

Anime Hair Studio is a separate application and is not bundled with Batshit. This template contains Batshit-owned creative project data and an embedded Batshit head calibration, not Anime Hair Studio software or source code. Review Anime Hair Studio's current license and make sure you have rights to every hairstyle you import or distribute.
