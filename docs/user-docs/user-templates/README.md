# User Templates

This folder contains the public-safe template files copied into the generated docs site.

Current launch-facing template guidance lives in [../reference/templates.md](../reference/templates.md).

- `batshit-anime-hair-studio/` contains Batshit's versioned Base Female Anime Hair Studio project template. It contains Batshit-owned project data and an embedded Batshit head calibration; it does not include the Anime Hair Studio application or source code.
- `batshit-official-n8n-workflow-templates/` contains the official public-safe n8n workflow source material.
